# 📋 Полный список команд сервера Mineloupe

Здесь собраны все команды установленных плагинов (**Zombie Infection System**, **World Border**), их параметры, права доступа и примеры использования.

---

## ☣ 1. Zombie Infection System (`/zombie`, `/zombiespawn`)

Основной плагин заражения, распределения классов зомби, инкубации и спавна.

### Команды для всех игроков
| Команда | Описание | Пример |
|---|---|---|
| `/zombie info` | Показывает ваш текущий статус (человек / инкубация / зомби), текущий класс и число совершенных заражений | `/zombie info` |
| `/zombie info <игрок>` | Показывает статус, класс и статистику другого игрока | `/zombie info MrRamtok` |

---

### Команды управления спавном зомби (Admin / OP)
| Команда | Описание | Пример |
|---|---|---|
| `/zombie setspawn` | **Устанавливает точку спавна зомби** на вашей текущей позиции (координаты $X, Y, Z$, угол обзора $Yaw, Pitch$ и измерение). Все умершие зомби после таймера респауна возрождаются здесь! | `/zombie setspawn` |
| `/zombie setspawn <x> <y> <z> [измерение]` | Устанавливает точку спавна зомби по точным координатам | `/zombie setspawn 100 65 -250 Overworld` |
| `/zombie spawn` | Телепортирует вас на установленную точку спавна зомби | `/zombie spawn` |
| `/zombie spawn <игрок>` | Телепортирует указанного игрока на точку спавна зомби | `/zombie spawn Steve` |
| `/zombiespawn set` | *Быстрый алиас:* Установить спавн зомби на текущем месте | `/zombiespawn set` |
| `/zombiespawn [игрок]` | *Быстрый алиас:* Телепорт на спавн зомби | `/zombiespawn` |

---

### Команды управления заражением и игроками (Admin / OP)
| Команда | Описание | Пример |
|---|---|---|
| `/zombie infect <игрок> [класс]` | Принудительно превращает игрока в зомби. Если класс не указан — выбирается случайный класс. | `/zombie infect Steve tank` |
| `/zombie reset <игрок>` | Полностью излечивает игрока (возвращает в статус человека, сбрасывает здоровье до 20 HP, восстанавливает стандартную скорость и удаляет теги зомби). | `/zombie reset Steve` |
| `/zombie class <игрок> <класс>` | Меняет класс уже заражённого игрока. Применяются новые характеристики HP, скорости и эффектов. | `/zombie class Steve runner` |
| `/zombie list` | Выводит в чат подробный список всех живых зомби (с их классами) и игроков, находящихся на стадии инкубации (с таймером). | `/zombie list` |
| `/zombie reload` | Перезагружает конфигурационный файл `config.toml` плагина без перезапуска сервера. | `/zombie reload` |

#### Доступные классы зомби:
- `normal` — **Обычный** (20 HP, 1.0x скорость, базовый зомби).
- `tank` — **Танк** (40 HP, 0.8x скорость, повышенное здоровье).
- `runner` — **Бегун** (16 HP, 1.2x скорость, высокая мобильность).
- `glass_cannon` — **Стеклянная пушка** (12 HP, 1.15x скорость, высокий урон 1.5x).
- `infector` — **Инфектор** (18 HP, 1.0x скорость, +15% к шансу заразить жертву).

## 🌐 2. World Border (`/worldborder`, `/wb`)

Плагин ограничения мира с защитой границ, предупреждениями, отталкиванием/телепортом и уроном.

| Команда | Описание | Пример |
|---|---|---|
| `/wb` или `/wb info` | Показывает текущее состояние границы: форму, координаты центра, радиус и параметры урона. | `/wb info` |
| `/wb set <радиус>` | Устанавливает радиус границы мира (в блоках от центра). | `/wb set 500` |
| `/wb center` | Устанавливает центр границы мира на вашей текущей позиции $X, Z$. | `/wb center` |
| `/wb center <x> <z>` | Устанавливает центр границы мира по заданным координатам $X$ и $Z$. | `/wb center 0 0` |
| `/wb shape <square\|circle>` | Меняет геометрическую форму границы: `square` (квадрат) или `circle` (круг). | `/wb shape square` |
| `/wb bypass` | Включает/выключает режим обхода границы для себя (позволяет админу выходить за границу без получения урона и телепорта). | `/wb bypass` |
| `/wb bypass <игрок>` | Включает/выключает режим обхода границы для указанного игрока. | `/wb bypass Steve` |
| `/wb reload` | Перезагружает конфигурацию границы `config.toml`. | `/wb reload` |

## ⚙ 3. Основные команды сервера (Vanilla Bedrock / OP)

| Команда | Описание | Пример |
|---|---|---|
| `/op <игрок>` | Выдать права оператора (администратора) игроку | `/op MrRamtok` |
| `/deop <игрок>` | Забрать права оператора у игрока | `/deop MrRamtok` |
| `/gamemode <s\|c\|a\|spectator> [игрок]` | Изменить режим игры (`survival`, `creative`, `adventure`, `spectator`) | `/gamemode c` |
| `/tp <x> <y> <z>` | Телепортация по координатам | `/tp 0 70 0` |
| `/tp <игрок1> <игрок2>` | Телепортация одного игрока к другому | `/tp Steve Alex` |
| `/time set <day\|night\|число>` | Установить время суток | `/time set day` |
| `/weather <clear\|rain\|thunder>` | Установить погоду | `/weather clear` |
| `/difficulty <easy\|normal\|hard>` | Установить сложность мира | `/difficulty normal` |
| `/kill [игрок]` | Убить сущность или игрока | `/kill @e[type=zombie]` |
| `/stop` | Корректная остановка сервера с сохранением мира | `/stop` |
